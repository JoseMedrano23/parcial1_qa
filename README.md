# 🎓 Sistema de Inscripciones Académicas

Un sistema completo para la gestión de inscripciones entre estudiantes y docentes, desarrollado en PHP usando arquitectura orientada a objetos y patrones de diseño.

## 📋 Descripción

Este proyecto implementa un sistema de inscripciones que permite:
- ✅ Registrar docentes con materias y departamentos
- ✅ Crear estudiantes con grados académicos
- ✅ Gestionar inscripciones estudiante-docente
- ✅ Buscar y filtrar información
- ✅ Generar estadísticas por departamento
